# Block Impact Lab

Block Impact Lab is an open-source NVIDIA Omniverse Kit extension for experimenting with rigid-body physics, procedural masonry, projectile impacts, keyboard control, and MIDI-controlled cannon aiming.

## Features

- Procedurally generated circular masonry tower
- PhysX rigid-body simulation
- Cannon with azimuth and altitude control
- Keyboard aiming
- Korg SQ-1 MIDI aiming
- Multiple self-cleaning projectiles

## Dependencies

This project depends on NVIDIA Omniverse Kit and PhysX.

NVIDIA Omniverse, Kit SDK, PhysX, and related NVIDIA software are separate dependencies and are governed by their respective NVIDIA license terms.

Python dependencies used by the extension include:

- mido
- python-rtmidi

## Repository Scope

This repository contains the Block Impact Lab extension source code only.

It does not include NVIDIA Kit SDK, NVIDIA binaries, proprietary template files, or other NVIDIA-distributed software.
